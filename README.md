# PHẦN 1: NHẬT KÝ SUY LUẬN LOGIC (REASONING STEPS)

**Bước 1: Tính thu nhập khả dụng**

Thu nhập khả dụng = Tổng thu nhập - Thuế - Chi phí cố định.

**Bước 2: Tính khoản trả nợ**

Xác định số tiền trả nợ tối thiểu, ưu tiên các khoản nợ đến hạn.

**Bước 3: Tính khoản tiết kiệm**

Tiền tiết kiệm = Thu nhập khả dụng × 20%.

**Bước 4: Phân bổ chi tiêu linh hoạt**

Tiền còn lại = Thu nhập khả dụng - Tiền trả nợ - Tiền tiết kiệm.

**Bước 5: Kiểm tra ngân sách**

Tổng chi = Thuế + Chi phí cố định + Trả nợ + Tiết kiệm + Chi tiêu linh hoạt.

Đảm bảo tổng tỷ lệ phân bổ bằng 100%.
